## 용어
- 거래시간 h = (h-1)시 ~ h시 구간. 정오 12~14시 = 13·14, 저녁 19~21시 = 20·21
- 탄소집약도 = Σ(연료원별 거래량 x 계수) / Σ(거래량), 계절·월 평균도 합계끼리 나누는 가중평균
- ci_mid: IPCC 전과정 중앙값 / ci_min·ci_max: 최소·최대 / ci_direct: 직접배출
- day_type: 주말 + 공휴일 = 휴일, 나머지 = 평일

## 결정 기록 (계획서 3번·한계에 반영)
1. 음수 61건은 0 처리 (모두 '급전가능 재생에너지')
2. 계산 제외 5종: 양수, 급전가능 재생에너지, 기타, 폐기물, 전기저장장치(비중앙) = 전체 거래량의 1.18%
3. IGCC는 석탄 계수, LPG·연료전지·부생가스는 가스 계수로 가정, 가스압은 0
4. 경유·중유는 IPCC에 없어 보조 값(전과정 720, 직접 603/689) 사용
5. 바이오 직접배출은 0(생물기원), 수력 최대값 2200은 저수지 메탄 사례라 최대 시나리오를 키움
6. 공휴일은 holidays 패키지 사용 -> 공식 달력과 대조 필요
7. 에너지공단 환산계수(KEA_EF_G_PER_KWH)는 미정 -> 확인 후 스크립트 맨 위에 입력

### 용어 정의 (중요)
- 이동 비율 p = 저녁 19~21시에 쓰던 전력 중 정오로 옮기는 비율
- 절감량 = 이동량 x (저녁 탄소집약도 - 정오 탄소집약도)
- (가) 이동분 기준 = (저녁-정오)/저녁 | (나) 저녁 기준 = p x (가) | (다) 하루 전체 = p x 저녁 사용 비중 x (저녁-정오)/하루 평균
- 보고할 때는 반드시 분모를 함께 적는다

### 결정 기록 추가

| 파일 | 내용 |

### 주요 함수
- shift(kwh, from_start, to_start, duration, season, day_type, month, scenario): 활동 1건 이동 결과(g, 감소율)
- shift_band(...): 계수 4세트로 같은 이동을 계산해 범위로 보여 줌
- denominators(p, ...): 감소율 3가지 분모 (가)(나)(다)
- best_start(duration, earliest, latest_end, ...): 허용 시간 안에서 가장 깨끗한 시작 시각 순위
- daily_distribution(season, day_type): 날짜별 이동분 감소율 분포
- activity_defaults(category, ef_g_per_kwh): 품목별 라벨 CO2 대표값(환산계수가 있으면 kWh도)

### 엔진 가정 (한계에 기재)
- 활동은 일정한 전력으로 정수 시간 동안 돈다. 허용 시간은 07~22시. 자정을 넘으면 같은 날 유형을 쓴다
- 1kWh 옮길 때 감소량(g) = 도착 시각 CI와 출발 시각 CI의 차이. '옮기기 효과 / 줄이기 효과' = 이동분 기준 감소율 (같은 값)
- 테스트 T10이 시작 시각 24를 0시로 받아들이는 버그를 발견해 입력 검증을 추가함
